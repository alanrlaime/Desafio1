El agua es memoria: chhijchi uma (granizo), jallu uma (lluvia), juyphi uma (helada). Los yatiris leen el cielo.

Relato original

fuente oral Narra Emilio Kapkique (46 años). El cerro Huayna Kallami es el más importante, posee un laguito. En tiempo de siembra, los yatiris van a traer agua cristalina. Existen tres clases: chhijchi uma (granizo), jallu uma (lluvia) y juyphi uma (helada). Deben traer jallu uma para que llueva; si traen helada o granizo, el clima se torna adverso.

Archivo Oral, Carrera de Literatura, diciembre 2010: p. 526

Adaptación · datos + IA

El relato se interpreta como un sistema de clasificación climática basado en conocimiento ancestral. Las tres aguas se modelan como variables latentes que afectan la productividad agrícola. La IA (NLP + clustering) extrae patrones de las narrativas orales y los vincula con datos meteorológicos.

Problemáticas y decisiones

  • Limitaciones del plan gratuito: Gemini y Crok tienen restricciones de uso diario, lo que ralentizó el proceso.
  • Flow resultó mejor para refinar prompts porque permite iterar más rápido y con mejor control semántico.
  • Crok fue superior para imágenes porque genera ilustraciones más detalladas y coherentes con la narrativa andina.
  • Gemini fue la mejor opción para el guion y la estructura cinematográfica de los 9 bloques.

Mención Ciencia de Datos · análisis

Se aplicó NLP para extraer entidades (tipos de agua, cerro, yatiri) y clustering sobre narrativas similares. Se correlacionaron las menciones de “chhijchi uma”, “jallu uma” y “juyphi uma” con datos de precipitación y temperatura de la zona (SENAMHI). El modelo identifica patrones de conocimiento empírico que coinciden con fenómenos meteorológicos.
